状态：用户已确认三项决策，第一阶段功能已实现。MP4 已完成端到端验证；旧 CSV 的末端修订等待确认后导入，真实 VRS 验收等待样例。每部分以本地 Git commit 记录。

## 技术栈

| 层级 | 已采用 | 选择理由 |
| --- | --- | --- |
| 前端 | React + TypeScript strict + Vite，npm 锁文件 | 本地桌面浏览器应用，独立 Python 媒体后端。支持清晰的组件边界与类型检查。 |
| 路由和服务数据 | React Router、TanStack Query，标注编辑使用局部 reducer | URL 记录素材、标签页和列表筛选；服务数据统一刷新，时间轴操作集中处理。 |
| UI | CSS Modules + 共享设计变量，Radix Dialog/Dropdown/Tooltip 等交互原语，Tabler Icons | 延续黑白灰、Geist/Geist Mono、黑色主按钮及既定图标；复用可访问的弹窗和键盘交互。 |
| 后端 | Python 3.12 + FastAPI + Pydantic + Uvicorn | 文件扫描、标注校验、抽帧与 Aria Python API 在同一个本地服务完成。 |
| 数据索引 | SQLite + SQLAlchemy 2 + Alembic | 保存稳定素材 ID、路径、元数据、帧组和引用关系，迁移可追踪。JSON 标注文件是区间内容来源。 |
| 媒体 | FFmpeg + ffprobe；Project Aria Tools | MP4 元数据、时间戳、代理与抽帧；VRS 流、标定及 DEVICE_TIME 映射。 |
| 工程检查 | ESLint、TypeScript、Ruff；pytest、真实浏览器核心流程 | 测试集中覆盖路径与删除、保存冲突、时间轴、准确抽帧和浏览器流程。 |

开发时通过 Vite 的 /api 代理连接本地 FastAPI；打包后由 FastAPI 提供页面和媒体接口。默认只监听 127.0.0.1。前端调用以素材 ID 为入口，后端解析真实路径。依赖在实施时确认兼容版本并锁定。

参考依据：[React 的 Vite 与 TypeScript 说明](https://react.dev/learn/build-a-react-app-from-scratch)、[Vite 环境要求](https://v8.vite.dev/guide/)。

## 数据合同

工作目录由后端集中配置，默认指向当前项目。

```text
data/                                   原始 MP4/VRS
app/frontend/                           React 应用
app/backend/                            Python 应用与独立环境
workspace/app.db                         素材、标注、帧组和处理任务索引
workspace/previews/<asset_id>/           可重建播放代理和时间映射
workspace/annotations/<asset_id>/
  draft.json
  versions/v001.json                     后续评估快照
workspace/frames/<asset_id>/<set_id>/
  frame_000000.jpg
  manifest.json
```

set_id 表示整段录像按固定 0.1 秒间隔生成的一套帧缓存。缓存匹配由源哈希、流、时间基准、全视频模式、间隔、分辨率与抽帧版本共同决定。图片不会加入原录像列表；历史按目标生成的旧帧组保留在磁盘，不混入当前界面。

- 标注内部用整数毫秒，半开区间 [start_ms,end_ms)。0.1 秒吸附用于可编辑边界，不舍入录像真实结束时间。
- 未分类使用 null，unclear 是独立有效标签。P0–P4/unclear 共用一份带版本的阶段定义，供图例和后续 Prompt 使用。
- annotation draft 记录 asset_id、源哈希、时长、时间基准、schema/标签版本、revision、区间和保存时间。保存失败不显示 Saved。
- 帧清单记录全视频缓存 ID、素材及源哈希、schema/extractor 版本、固定间隔、每张图对应的全部请求时间、实际时间、原始帧索引、尺寸及相对路径。同一实际帧去重但保留全部请求映射；VRS 还记录 DEVICE_TIME。模型预测目标与上下文选择属于后续模型模块。
- 文件原地替换后，标注和帧组必须显示 source changed 并重新检查。路径移动尽量保留稳定 ID，内容重复保留独立素材记录并提示相同哈希。
