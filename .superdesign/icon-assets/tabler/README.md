# Icon source for Phase Lab concepts

The UI concepts use the **Tabler Icons** family listed in [Iconstack](https://iconstack.lovable.app/). All copied SVG files in this directory come from the [official Tabler Icons repository](https://github.com/tabler/tabler-icons/tree/main/icons/outline). They are embedded inline in the imported concept HTML to keep rendering stable.

The original MIT license notice is in [LICENSE](LICENSE). The icons are design assets for the concept screens; they do not imply that the app itself has been implemented.
